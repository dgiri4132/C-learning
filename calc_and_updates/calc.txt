A scope is a region of program text. A name is declared in a scope is valid (is "in scope")
from the point of its declaration until the end of the scope in which it was declared. For example:

There are several kinds of scopes that we use to control where our names can be used:

The global scope: the area of text outside any other scope.
A module scope : the area of text within a module.
A namespace scope : a named scope nested in the global scope or in another namespace
A class scope : the area of text within a class.
A local scope : between {...} braces of a block or in a function argument list
A statement scope : in a for-statement

The main purpose of a scope is to keep names local, so that they won't interfere with names 
declared elsewhere. For example:

int max(int a, int b)   max is global; a and b are global
{
    int m;      m is local
    if(a>=b)
        m = a;
    else 
        m = b;
    return m;
}

int abs(int a)
{
    return (a>=0)? a: -a;
}
The ? that is used in abs() is called an arithmetic if or a conditional expression. The value of 
(a>=0)?a:-a is a if a>=0 and -a otherwise. 
Remember : try to keep names as local as possible. Real programs have many thousands of named 
entities hence creating the need to making most programs local.

Pass-by-const-reference
When values are large, copying can be costly.

let's look at the example below

void print(vector<double> v)
{
    cout << "{";
    for (int i = 0; i<v.size();++i){
        cout <, v[i];
        if(i!=v.size()-1)
            cout << ",";
    }
    cout << "}\n";
}
Here, if we use 
vector <double> vd1(10);
it will have to copy 10 times as it is in a loop right.

But if we use 
vector <double> vd2(1000000);
 we would have to copy numerous times. 
 So, here the question arises: Why do we have to copying anything? Why can't we just print?
 what we do is we need a way of giving our print() function "the address" of
 the vector to print() rather than the copy of the vector. Such an address is called a reference
 It is used in the way below:
 void print(const vector<double>& v)
 {
    cout <, "{";
    for (int i = 0; i<v.size(); ++i){
        cout << v[i];
        if (i!= v.size()-1)
            cout << ",";
    }
    cout << "}\n";
 }
 So you use normal pass-by-value when you need your own independent copy to play with or the type is tiny
 pass by const& when you want to look at something without copying it.
