Chapter 7.1 start 
A Declaration is a statement that intorduces a name into a scope
A Definition is a type of declaration that also fully specifies the entity declared.
Both are offered in C++ because the definition/declaration distinction allows us to separate a program into many parts that can be compiled separately.

The extern keyword used in the second declaration of x simply states that this declaration of x isn't 
a definition.

There are many kinds of entities that a programmer can define in C++. The most interesting are
Variable and constants
functions
namespaces
modules
types 
templates 
concepts
